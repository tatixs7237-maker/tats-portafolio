# TATS — Personal Portfolio Website

Sitio web estático, sin frameworks y sin coste de hosting.

## Archivos
- `index.html` — estructura y contenido.
- `style.css` — diseño, responsive y animaciones.
- `script.js` — menú móvil, animaciones y tarjetas de vídeo.
- `assets/tats-logo.png` — logo de TATS.
- `assets/tats-marble.png` — fondo/estética mármol.

## Personalización rápida

Abre `index.html` y cambia:
1. `YOUR_EMAIL@example.com` por tu email.
2. Los enlaces de Instagram, YouTube y TikTok.
3. `VIDEO_URL_1`, `VIDEO_URL_2`, `VIDEO_URL_3` por los enlaces de tus proyectos.
4. Los nombres y descripciones de los proyectos.
5. El texto de "About" para tu propia historia.

## Publicarla gratis con GitHub Pages

1. Crea una cuenta en GitHub.
2. Crea un repositorio nuevo, por ejemplo `tats-portfolio`.
3. Sube TODO el contenido de esta carpeta manteniendo la estructura.
4. En GitHub: Settings → Pages.
5. Selecciona "Deploy from a branch", la rama `main` y la carpeta `/root`.
6. Guarda y espera unos minutos.
7. GitHub te dará una dirección pública para tu web.

No necesitas comprar hosting.
